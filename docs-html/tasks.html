Overview

Kế hoạch triển khai chia toàn bộ hệ thống R1–R37 thành các bước code tăng dần, build-được. Trình tự: dựng hạ tầng (docker-compose: PostgreSQL/RabbitMQ/Keycloak/Kong/Prometheus/Grafana) và thư viện cross-cutting trước, sau đó hiện thực từng microservice nghiệp vụ (Java + Spring Boot 3.x), pipeline mô hình offline + Pricing_Service (Python + FastAPI bọc 36 artifact .joblib), rồi tích hợp liên dịch vụ, frontend (React + Vite + TS), bonus (CI/CD, monitoring, A/B, feature store), và cuối cùng demo đầu cuối 3 profile + README một-lệnh.

Mỗi microservice tuân kiến trúc phân lớp ở design §2.3 (Controller → Service @Transactional → Repository → PostgreSQL) kèm CorrelationIdFilter, GlobalExceptionHandler, HealthController, OutboxPublisher và Micrometer. Mọi số tiền là VND số nguyên (C-4). Giao tiếp đồng bộ qua Kong, bất đồng bộ qua RabbitMQ (outbox + DLQ).

Các sub-task kiểm thử được đánh dấu * (tùy chọn). Mỗi property-based test tham chiếu đúng một Property trong design §"Correctness Properties" và mệnh đề requirements mà nó kiểm chứng (Hypothesis cho Python, jqwik/JUnit cho Java, tối thiểu 100 iterations, tag Feature: dynamic-pricing-platform, Property {n}).

Quy ước hiện thực dùng chung (rút từ mã đã hoàn thành task 1–4.2)

Mọi task còn lại (4.3 trở đi) PHẢI bám sát các quy ước dưới đây, trích trực tiếp từ mã đã build được trong services/common, services/customer-service và pricing/common. Mục đích: phần còn lại đồng nhất tuyệt đối với phần đã làm. Mỗi task bên dưới chỉ nêu phần ĐẶC THÙ; các quy ước nền dùng lại ở đây.

A. Gradle module Java mới — sao services/customer-service/build.gradle: plugins java-library, io.spring.dependency-management, org.springframework.boot 3.3.5; implementation project(':services:common'); starters web, data-jpa, actuator, validation, security; org.flywaydb:flyway-core + org.flywaydb:flyway-database-postgresql; runtimeOnly 'org.postgresql:postgresql'; lombok compileOnly+annotationProcessor; test spring-boot-starter-test, net.jqwik:jqwik:1.8.2, testRuntimeOnly 'org.junit.platform:junit-platform-launcher'; kết bằng tasks.named('jar'){ enabled = false }. Service phát/tiêu thụ event thêm implementation 'org.springframework.boot:spring-boot-starter-amqp' (dùng @RabbitListener; RabbitTemplate/OutboxRelay đã có runtime từ common). Bỏ comment dòng include 'services:{svc}-service' trong settings.gradle. BOM spring-boot-dependencies:3.3.5 + Java 17 đã set ở root build.gradle (subprojects).

B. Package — gốc dpp.{svc} (vd dpp.product, dpp.order); lớp {Svc}ServiceApplication @SpringBootApplication; subpackage controller/ service/ repository/ entity/ dto/ config/ client/ như dpp.customer.

C. application.yml — sao customer-service: server.port (customer=8081 → cấp tăng dần product=8082, order=8083, underwriting=8084, claims=8085, billing=8086, notification=8087; pricing FastAPI=8000), KHỚP target trong infra/kong/kong.yml ({svc}-service-upstream); datasource jdbc:postgresql://${ {SVC}_DB_HOST:localhost}:${ {SVC}_DB_PORT:54xx}/${ {SVC}_DB_NAME:{svc}_db}, user ${POSTGRES_USER:platform_user}, pass ${POSTGRES_PASSWORD}, hikari maximum-pool-size: 10; spring.jpa.hibernate.ddl-auto=none, open-in-view=false; spring.flyway.enabled=true, locations=classpath:db/migration; actuator expose health,info,prometheus. Biến DB env + port 5433–5440 đã có trong .env.example.

D. Flyway — src/main/resources/db/migration/V1__init_{svc}_schema.sql, bảng/cột snake_case + CHECK nội tuyến (vd chk_*, uq_*, idx_*), khớp tên bảng/cột design §5.x. Service phát event copy bảng outbox từ template services/common/src/main/resources/db/migration/V1__create_outbox_table.sql thành migration riêng (mỗi DB tự sở hữu outbox).

E. Entity — sao dpp.customer.entity: @Entity @Table(name="snake"), lombok @Getter @Setter, @Id UUID gán thủ công UUID.randomUUID() trong service (không @GeneratedValue), @Column(name=...) tường minh; JSONB qua @JdbcTypeCode(SqlTypes.JSON) columnDefinition="jsonb" kiểu Map<String,Object>/String (mẫu ProfileVersion.lineAttributes, OutboxEntity.payload). Tiền tệ là *_vnd BIGINT/long (C-4).

F. Controller/Service/DTO — controller @RestController @RequestMapping, inject qua constructor, @Valid @RequestBody, @ResponseStatus; service @Service @Transactional @Slf4j; DTO lombok + jakarta validation. Lỗi nghiệp vụ: throw new ServiceException(ErrorCode.X, details) (KHÔNG tự build response) — GlobalExceptionHandler của common sinh schema §7.1 {error_code, message, correlation_id, details}.

G. Bảo mật — config/SecurityConfig @EnableWebSecurity, csrf.disable(), permitAll /actuator/health+/actuator/prometheus+endpoint public của service, còn lại authenticated() (sao customer-service). Cô lập sở hữu: so khớp customer_id/subject từ JWT, sai → ServiceException(ErrorCode.FORBIDDEN_RESOURCE) (403).

H. Mã lỗi — dùng đúng hằng có sẵn trong dpp.common.api.ErrorCode (Java) và common.errors.ErrorCode (Python), đã đồng bộ: EMAIL_ALREADY_USED, INVALID_EMAIL_FORMAT, INVALID_PASSWORD_LENGTH, ACCOUNT_LOCKED, INVALID_CREDENTIALS, PROFILE_FIELD_OUT_OF_RANGE, INVALID_CATEGORICAL_VALUE, MISSING_REQUIRED_FIELDS, MISSING_FEATURES, UNSUPPORTED_LINE, MISSING_CHAMPION, CHALLENGER_NOT_CONFIGURED, QUOTE_EXPIRED, QUOTE_ALREADY_USED, UNDERWRITING_NOT_ELIGIBLE, PAYMENT_FAILED, FORBIDDEN_RESOURCE, POLICY_NOT_MODIFIABLE, ENDORSEMENT_DATE_OUT_OF_RANGE, INVALID_CLAIM_TRANSITION, OCCURRENCE_OUT_OF_COVERAGE, SERVICE_OVERLOADED, ROUTE_NOT_FOUND, UNAUTHENTICATED, SERVICE_UNAVAILABLE, VALIDATION_REPORT_UNAVAILABLE, INTERNAL_ERROR, BAD_REQUEST. Cần mã mới → thêm vào CẢ HAI enum (Java + Python) trước khi dùng.

I. Phát sự kiện (outbox) — inject OutboxPublisher (common), gọi outboxPublisher.enqueue(eventType, payloadJson) TRONG cùng @Transactional với ghi nghiệp vụ (atomic R19.4). OutboxRelay (common, poll mỗi 2s) tự publish vào exchange platform.events, routing key = eventType. Tên event = đúng routing key trong infra/rabbitmq/definitions.json: PolicyIssued, EndorsementApplied, PolicyRenewed, PolicyCancelled, InvoicePaid, ClaimStatusChanged, ChampionPromoted, ChampionRolledBack. Payload là JSON String (Jackson) chứa tối thiểu khóa nghiệp vụ.

J. Tiêu thụ sự kiện — @RabbitListener(queues="...") trên đúng tên queue: policy.issued.queue, endorsement.applied.queue, policy.renewed.queue, policy.cancelled.queue, invoice.paid.queue, claim.status.changed.queue. Dedup theo header X-Event-Id/messageId (R10.1) + khóa nghiệp vụ idempotent. Redeliver 3 lần → DLQ (x-delivery-limit=3 đã cấu hình).

K. Pricing (FastAPI) — code tại pricing/app/ (tách khỏi pricing/common); app/main.py tạo FastAPI(...) rồi gọi setup_common_middleware(app) (đăng ký correlation/metrics//metrics//health/errors §7.1) TRƯỚC khi include router nghiệp vụ; lỗi nghiệp vụ raise ServiceException(ErrorCode.X, details=...). Persistence dùng SQLAlchemy + Alembic (hoặc migration SQL thuần đặt cùng pattern), DB pricing_db port 5440. Test pytest + Hypothesis (thêm hypothesis vào pricing/requirements.txt).

  • POST /orders (10.2): cổng thẩm định + hiệu lực quote — UNDERWRITING_NOT_ELIGIBLE (409, DECLINE/REFER chưa duyệt), QUOTE_EXPIRED (409, expires_at < now), QUOTE_ALREADY_USED (409, vi phạm UNIQUE order_.quote_id); khóa final_premium_vnd lấy từ quote.

  • POST /claims/fnol (12.2): OCCURRENCE_OUT_OF_COVERAGE (400, occurrence_date không thuộc segment nào), FORBIDDEN_RESOURCE (403, không sở hữu policy).
